# Издержки: замер 12.10.2026 и что резать

Цены — API Anthropic для Claude Opus 5.5: вход $4, выход $20, запись в кэш на час $8, чтение
кэша $0,20 за миллион токенов. На подписке это не деньги, а лимит: чем меньше токенов, тем больше
роликов влезает до упора.

## Замер

**Монтаж одного ролика (IMG_1803, своя сессия, 6 ходов, 68 запросов): ≈ $3,90.**
- чтение кэша 7,6 млн токенов — $1,52 (39%): каждый запрос перечитывает весь разговор;
- запись в кэш 0,17 млн — $1,36 (35%);
- ответы модели 50 тыс. — $1,00 (26%), из них больше половины — page.py.

Контекст разговора рос с 29 тыс. (первый ход) до 163 тыс. (последний). Больше всего его раздули
не картинки (сетка кадров — около 1,6 тыс. токенов), а чтение кода и данных целиком:
- `work/IMG_1803.words.json` — 26 тыс. символов, ради нескольких таймингов слов;
- `scripts/kit.py` — ~35 тыс. символов, ради сигнатур функций;
- чужой `work/IMG_3317/page.py` — 15 тыс. символов, как образец каркаса страницы.

**Сессия разработки (эта, 10–12.10): ≈ $155, 819 запросов**, контекст запроса дорос до 763 тыс.
токенов — одно действие стоит ≈ $0,15 только на чтение контекста, в свежей сессии ≈ $0,006.

**Ловушка учёта.** `total_cost_usd` в ответе Claude Code (`claude -p --resume`) — нарастающий итог
разговора, а не цена хода. Студия показывает его под каждым ходом как цену хода, и сумма по ходам
завышает цену в разы (у IMG_1803: «$13,41» вместо $3,90). Починено 13.10: студия показывает
«ход ≈ $Δ · разговор ≈ $итог» — цена хода считается разницей с прошлым итогом той же сессии
(`brain.turn_cost`), старые разговоры досчитываются при открытии; проверка — в самопроверке.

## Что резать — по выгоде

1. **Новая задача — новая сессия** (как «один ролик — одна сессия»). Разработку не вести неделями
   в одном окне: всё нужное и так лежит в файлах (AGENTS.md, скиллы, docs/). Экономия ~90% токенов
   разработки — самая большая статья.
2. **Худой контекст монтажа** — ожидаемо −25…35% цены ролика:
   - короткая шпаргалка API (`kit`, `viz`: функции, параметры, пример) в скилле вместо чтения
     `kit.py` целиком;
   - `scripts/new_page.py <имя>` — каркас page.py (импорты, Take, звуки, build_page) вместо чтения
     чужой страницы; мозг пишет только содержание — меньше и чтения, и вывода;
   - `scripts/words.py <имя> --find слово` — тайминги нужных слов вместо всего words.json.
3. **Модель.** Sonnet 5.5 вдвое дешевле ($2/$10). Риск — качество режиссуры; сначала A/B на одном
   ролике (тот же исходник, обе модели), решение — по ролику, а не по цене.
4. **Меньше перерендеров.** Лишний рендер с осмотром — ход ($0,4–0,9) и 7 минут машины. Правило
   «одна версия» и проверки до рендера (звуки, серые зоны, засвет) уже режут это; дальше — снимки
   ключевых кадров (`hyperframes snapshot`) до рендера вместо «отрендерить и посмотреть».
5. **Время машины** (не деньги, но ожидание): вырезка человека кодируется 3,5–4 мин (VP9 с
   прозрачностью) — ускорить настройки кодирования; стилям без «текста за спиной» маска не нужна
   вовсе (`cutout=False`) — минус ~6 минут подготовки. **Сделано 22.10.2026:** маска считается после
   страницы и только по её окнам, а без окон не считается (`matte.py --windows page`, замер — docstring matte.py).

Пункт 0 — починить показ цены в студии (ловушка учёта выше): без честной цены резать вслепую.

## Замер 23.10.2026: автопилот, 15 роликов

Аналитик: 23 первых хода по $0,44 и 42 исправления по $0,15 — $16,6, **чистых первых ходов 0 из 15**. Доводка руками в
длинной сессии разработки (373 вызова, контекст в среднем 334 тыс.) — $36,6. Итого ≈ $3,5 на ролик.

Причины и что сделано:
1. Аналитик получал одно название проверки без подробностей и правил вслепую → `verify(out=…)` отдаёт элемент, текст и
   секунду, `analyst.triage` переводит их в `items[k]` партитуры.
2. Механику гонял Opus → двойной текст прячет машина (`analyst.autofix`, до двух проходов без ИИ).
3. Поломку сборки ИИ не исправит → `BuildBroken`: стоп без хода аналитика. Повод — CSS: общий `.big` из kit растягивал
   подпись оси «Чертежа» у правого края на кадр, и IMG_3683/IMG_3684 переписывали партитуру 6 раз впустую.
4. Исправления — на среднем усилии (`FIX_EFFORT`), первый ход — на высоком.
5. Учёт: `total_cost_usd` накопительный — в analyst.jsonl теперь `cost` хода и `cost_total` разговора (лог до 23.10
   суммировать нельзя: завышает вдвое).

Цель — первый ход чистый в 80% роликов, ≈ $1 на ролик вместо $3,5. Мерить по analyst.jsonl, а не на глаз.

## 24.10.2026: что ещё срезано

- **Сток без длинной сессии.** Автопилот берёт сток сам: аналитик пишет английский запрос (`kind stock`), машина ищет,
  проверяет чёткость и длину и режет (`stock.auto`, очередью). 23.10 эту работу делала руками сессия за $36.
- **Проба до маски и рендера.** Первый ролик проекта в пачке останавливается на графике — человек смотрит
  предпросмотр и жмёт «Дальше» (`autopilot --probe/--finish`). Переделка стиля после рендера стоила ход ИИ и минуты
  маски и рендера на каждый ролик пачки; теперь — один раз на проект и без рендера.
- **Вкус автора** (`taste.py`) и **заказ** (`analyst.order`) — во вход аналитика: меньше браков из-за «не то, что хотел».
- Слита ветка «своя идея» (`score.novelty`): повтор прошлых роликов ловится до рендера, а не после.
