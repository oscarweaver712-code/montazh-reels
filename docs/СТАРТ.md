# Старт на новой машине (Windows или Mac) — 23.10.2026

Лист для человека, который ставит студию монтажа себе. Движок — общий, клиенты — у каждого свои.

## Что нужно заранее

- Windows 10/11 (x64) или Mac на Apple Silicon. Места — ~15 ГБ (модели, окружения, браузер для рендера).
- Подписка **Claude** (Pro или Max) — ИИ монтирует через Claude Code. Codex не нужен: всё работает и без него.
- Доступ к репозиторию движка на GitHub (приглашение от Валеры).
- **Ключ Pixabay** — бесплатно, минута, у каждого свой: зарегистрируйся на https://pixabay.com (можно через Google),
  открой https://pixabay.com/api/docs/ — ключ виден в разделе «Parameters» у поля key. Без него установка не закончится:
  стоки 4K без водяных знаков (правило «не мутнее 720p во весь кадр»). Ключ Pexels — по желанию: у них вертикальные
  клипы, но 23.10.2026 новые ключи на паузе.

## Установка

1. Скачай репозиторий в папку, например `Монтаж Reels` (кириллица и пробел в пути — можно):
   `git clone <ссылка на репозиторий движка> "Монтаж Reels"`.
2. Двойной клик: **«1 Установка — Windows.bat»** (на Mac — «1 Установка — Mac.command»). Поставит ffmpeg, Node.js, uv,
   Python-окружения, модели (речь ~1,6 ГБ), браузер для рендера и в конце прогонит самопроверку (~3 мин).
      По пути спросит ключи стоков (вставка не видна — так и надо). В конце должно быть «✓ всё чисто». Красное — пришли вывод Валере.
3. Установи Claude Code и войди: в студии кнопка «ИИ» вверху справа → Claude → установить и войти
   (или в PowerShell `irm https://claude.ai/install.ps1 | iex`, на Mac `curl -fsSL https://claude.ai/install.sh | bash`,
   потом `claude` и вход по подписке).
   На Windows Claude Code нужен Git Bash — он ставится вместе с Git на шаге 2.

## Первый ролик

1. Открой папку в терминале и запусти `claude` — студия откроется в браузере сама (http://127.0.0.1:8765).
   Без терминала: «2 Монтаж — Windows.bat».
2. **Свой проект.** На чистой установке есть пустой «Мои ролики». Для каждого заказчика — свой проект:
   «Проект → Новый проект».
3. **Анкета проекта** («Проект → Настроить проект»): о чём ролики, для кого, где публикуем, характер монтажа, чего
   нельзя. Без обязательных ответов ИИ проект не монтирует. Здесь же:
   - **референсы** — ролики, которые нравятся: студия сама их разберёт (темп склеек, текст в кадре) и учтёт в выборе шаблона;
   - **шрифты проекта** — шрифты бренда заказчика (.ttf/.otf); лежат с проектом и работают одинаково на Windows и Mac.
   После сохранения студия сама поставит **шаблон** — почерк монтажа, ближайший к анкете, видео и референсам.
   Не тот — смени там же одним нажатием.
4. Перетащи видео в «Медиа» слева → «▶ Запустить ИИ-монтаж». По умолчанию монтаж идёт **сессией** в окне справа:
   видно каждый шаг, можно вмешаться словами. «＋ новая» — свежая сессия того же ролика с передачей дел.
   Автопилот (дешевле, без разговора) — переключатель под кнопкой и пачка из нескольких видео.
5. Готовый ролик — в `projects/<проект>/output/`. Принять — «✓ принять» у версии: черновики уберутся.

## Что у тебя не будет работать — и это нормально

- **ИИ-клипы Google Flow (Omni/Veo) и картинки через Codex** — это подписки Валеры. Без них монтаж полный: графика,
  фото, стоки, визуализации. Свой Flow — только по своей подписке.
- **Проекты Валеры** (Антишкола и заказчики) — их у тебя нет: движок общий, клиенты — у каждого свои.

## Свои клиенты в своём репозитории (по желанию)

Проекты и решения роликов (`projects/`, `work/`) в git движка не попадают. Хранить их и переносить между машинами —
свой приватный репозиторий на GitHub:

```
.venv\Scripts\python.exe scripts\clients.py init https://github.com/<ты>/<мои-клиенты>.git   # один раз
.venv\Scripts\python.exe scripts\clients.py save "что сделал"                             # сохранить и отправить
.venv\Scripts\python.exe scripts\clients.py clone <ссылка>                                 # на другой машине
```

(на Mac — `.venv/bin/python scripts/clients.py …`)

## Обновления движка

`git pull` в папке — и перезапусти студию (она сама перезапустится при следующем старте `claude`, если ничего не
монтирует). После обновления можно прогнать `.venv\Scripts\python.exe scripts\selfcheck.py`.
