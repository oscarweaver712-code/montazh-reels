# Монтаж Reels — автопайплайн

Кидаешь сырое видео в `input/` и забираешь готовый ролик из `output/`: вертикаль для Reels,
Shorts и TikTok или горизонталь для YouTube. Всё считается локально на этой машине, видео
никуда не уходит.

Конвейеров два. **Режиссёрский** — монтаж уровня референсов: текст за спиной, карточки,
слежение за лицом, звуки. Где и чем ударить, решает «мозг» — Claude Code или Codex, на выбор,
а графика собирается в HyperFrames. **Быстрый** — рез пауз, субтитры, цвет и голос без графики,
за пару минут.

Управлять всем удобно из **студии** — страницы в браузере, которая открывается сама, когда
запускаешь `claude` или `codex` в папке проекта.

## Быстрый старт

1. **Скачай проект:** на странице репозитория **Code → Download ZIP** и распакуй (репозиторий закрытый —
   сначала прими приглашение, оно придёт на почту).
2. **Установи один раз:** двойной клик по **«1 Установка — Mac.command»** или **«1 Установка — Windows.bat»** — эти файлы
   стоят первыми в папке. Всё ставится само, минут 15–30 (модели качаются из интернета), в конце —
   самопроверка. Если macOS не пускает — правый клик → «Открыть»; если Windows спрашивает про файл
   из интернета — «Подробнее» → «Выполнить в любом случае».
3. **Работай:** двойной клик по **«2 Монтаж — Mac.command»** или **«2 Монтаж — Windows.bat»** — откроется студия в
   браузере. Или открой папку в терминале и запусти `claude` или `codex`: студия откроется сама.

## Установка — Mac или Windows

Нужно: Mac на Apple Silicon (M1 и новее) или Windows 10/11 (64 бит), 16 ГБ памяти, около 15 ГБ
на диске и хотя бы один «мозг»: [Claude Code](https://claude.com/claude-code) или
[Codex CLI](https://developers.openai.com/codex). На Mac ещё [Homebrew](https://brew.sh), на Windows —
winget (он есть в Windows 11 и в «App Installer» из Microsoft Store).

1. Прими приглашение в репозиторий на GitHub (придёт на почту), затем скачай проект:
   `gh repo clone oscarweaver712-code/montazh-reels` или на странице репозитория
   **Code → Download ZIP**.
2. Двойной клик по установщику: на Mac — `1 Установка — Mac.command` (если macOS не пускает — правый
   клик → «Открыть»), на Windows — `1 Установка — Windows.bat`. Ставит ffmpeg (сборку с libass), Node, uv,
   окружение Python, модели (речь ~1,6 ГБ, лица, маска человека, текст в кадре) и браузер для
   рендера, в конце гоняет самопроверку. Повторный запуск безопасен.
3. Для Codex — один раз: при первом запуске `codex` в папке проекта он спросит, доверять ли
   хукам проекта (`/hooks`). Разреши — иначе студия не будет открываться сама. Если Codex
   пишет, что модели нужна новая версия, — `codex update`.

## Как монтировать

1. Открой папку проекта в терминале и запусти `claude` или `codex`. Студия откроется в
   браузере сама (http://127.0.0.1:8765). Без агента её поднимает двойной клик по
   `2 Монтаж — Mac.command` или `2 Монтаж — Windows.bat`.
2. Перетащи видео в студию — оно ляжет в `input/`.
3. Выбери ролик и задай, какой нужен результат: цели (охват, удержание, доверие, сохранения,
   продажи), формат (9:16, 16:9, 1:1, 4:5) и стиль. Если нужно сравнение, добавь варианты для A/B.
4. Нажми **«Смонтировать с мозгом»**: мозг смонтирует по брифу, тяжёлые шаги пройдут через
   очередь. Для монтажа без графики есть **«Быстрый монтаж в стиле»**: рез, субтитры и цвет
   за пару минут. Готовое появится в списке выпусков, его можно смотреть прямо в студии.

5. Понравилось — **«Апрув»** у выпуска: он станет конечным вариантом, а черновые версии и сырые
   рендеры этого ролика удалятся (список покажут до удаления).

**Один ролик — одна сессия мозга.** У разговора с агентом конечный контекст: если монтировать
десять роликов в одной сессии, каждый следующий выходит хуже. Поэтому студия держит разговоры
каждого ролика отдельно, а пачку («Пачкой: новые из input/» в студии или
`.venv/bin/python scripts/batch.py` из терминала) ведёт по одному ролику, и у каждого — новая
сессия. Агент в терминале на «смонтируй новые» сам запустит пачку.

Решения по каждому ролику лежат в `work/<имя>/` (`brief.json`, `edit.json`, `director.json`,
`page.py`, `approved.json`) — их можно поправить словами («убери карточку на 12-й секунде») и пересобрать.

## Студия

| | |
|---|---|
| Ролики | Плёнка из шести кадров — этапы: текст, дубль, лицо, маска, графика, ролик |
| Выхлоп | Цели 0–5 и **спектр стилей**: слева проверенный мейнстрим, справа антитренд, красная линия — смелость. Чем крупнее точка, тем лучше стиль под цели |
| Стили | 13 карточек: что видит зритель, почему работает, чем рискуем, откуда приём. «Основной» и «в A/B» |
| Мозг | Claude или Codex, переключатель сверху. У каждого ролика свои разговоры. «Безопасно» — правка файлов и скрипты проекта; «Полный доступ» — без ограничений |
| Пачка | Новые ролики по одному, каждый в своей сессии мозга; после очереди разговор продолжается сам |
| Апрув | Принять выпуск конечным вариантом и убрать его копии |
| Очередь | Внизу: что считается сейчас, что ждёт (можно убрать), что упало. Тяжёлое идёт строго по одному |

Сервер студии отвечает только этой машине и принимает изменения только со своей страницы
(ключ в странице), поэтому чужой сайт в соседней вкладке не запустит мозг. Остановить:
`.venv/bin/python scripts/studio_up.py --stop`. Не открывать при старте агента:
`export REELS_NO_STUDIO=1`.

## Визуализации данных

Когда в речи есть число, проценты, рост, сравнение, формула или график функции, мозг сам ставит
визуализацию. Он решает по скиллу `viz` (`.agents/skills/viz/SKILL.md`), как часто — задаёт стиль.
- Готовые элементы из официального каталога HyperFrames (Apache-2.0) лежат в `presets/viz`:
  счётчик, столбики и линия, доли, падение, «до/после», гонка, карта мира, блок-схемы.
- Для математики есть свои: формула LaTeX (KaTeX) и график функции с корнями (`scripts/viz.py`).
- Всё лежит в проекте, рендер идёт без сети. Числа написаны по-русски, шрифты наши, с кириллицей.

## Стили и форматы

Стили лежат в `presets/styles/*.json`: «Вирусный: слово за спиной» (наш эталон), «Хормози»,
«Объясняю на фоне», «Сплит с залипалкой», «Мемный хаос», «POV-сценка», «Видео-эссе»,
«Учебная доска», «Документальный реализм», «Редакционная студия», «Мягкий спокойный»,
«Лоуфай, как с телефона», «Одна камера, без монтажа». В каждом — числа для обоих конвейеров
и указания режиссёру. Откуда они и что взяли у рынка — [docs/РЫНОК.md](docs/РЫНОК.md).

```bash
.venv/bin/python scripts/styles.py --goals trust=5,sales=4 --bold 0.7 --format 16:9   # подбор под цель
.venv/bin/python scripts/reels.py input/urok.mp4 --style video-essay --format 16:9     # быстрый монтаж в стиле
.venv/bin/python scripts/render_reel.py IMG_3317 --variant hormozi                       # вариант для A/B
.venv/bin/python scripts/analyze_reference.py work/ref.mp4      # «как у этого ролика»: темп, текст, цвет
.venv/bin/python scripts/timeline_view.py output/IMG_3317_v1.mp4 10 16   # кадры + звук + слова картинкой
```

Исходник может быть любых пропорций: под другой формат кадр перекадрируется по лицу
(`reframe.py`), а не режется по центру.

## Режиссёрский монтаж

Скажи Claude Code «смонтируй новые из input/» — дальше по скиллу `reels`
(`.claude/skills/reels/SKILL.md`, там же все ловушки). Шаги и где что лежит:

| Шаг | Команда | Что получается |
|---|---|---|
| Распознавание | `scripts/transcribe.py input/X.MOV` | `work/X.txt`, слова с таймингами |
| Чистовой дубль | `scripts/prep.py input/X.MOV` | `work/X/aroll.mp4` — подрезка по тишине, цвет, голос (решения в `work/X/edit.json`) |
| Камера и маска | `scripts/track.py`, `scripts/matte.py --cutout` | слежение за лицом, человек без фона для текста «за спиной» |
| Графика | `work/X/page.py` | `studio/X/index.html` — удары по словам, карточки, субтитры |
| Проверка страницы | `scripts/verify_page.py X` | за 2 с: ничего не залипнет в рендере, все ассеты на месте |
| Готовый ролик | `scripts/render_reel.py X` | `output/X_vN.mp4` — рендер, громкость −14 LUFS, проверка файла |

Пачка роликов идёт через очередь `scripts/jobqueue.py` (`work/_queue/`): строго один тяжёлый
процесс за раз, чтобы ноутбуком можно было пользоваться, пока считается.

## Быстрый старт (быстрый конвейер)

**Двойной клик по `2 Монтаж — Mac.command`** (на Windows — `2 Монтаж — Windows.bat`) — откроется студия в браузере. Монтаж без графики в один
клик — кнопка «Быстрый монтаж в стиле»; ручные настройки — в быстрой панели (ссылка
«Быстрая панель» в шапке студии, `http://127.0.0.1:8765/quick`): перетащил видео, покрутил
настройки, нажал «Смонтировать». Терминал не нужен. Монтаж из панели встаёт в ту же очередь,
что и всё остальное, — тяжёлое идёт строго по одному.

Студия живёт на этой машине (`127.0.0.1:8765`), наружу не смотрит, видео никуда не уходит.

Если удобнее из терминала:

```bash
.venv/bin/python scripts/reels.py                      # всё из input/
.venv/bin/python scripts/reels.py input/urok.mp4       # один файл
.venv/bin/python scripts/reels.py input/urok.mp4 --hook "Так делают 90% учеников"
```

Или просто скажи Claude Code: «смонтируй последнее видео» — подхватится скилл `reels`.

## Быстрая панель (`/quick`)

| | |
|---|---|
| Превью кадра | Настоящий кадр из твоего видео с субтитрами поверх — сразу видно, не перекрывают ли они тебя. Ползунком выбираешь момент кадра. Если видео уже распознавалось, в превью встают твои собственные слова |
| Шрифты | Выпадающий список. Свой добавляется кнопкой «Добавить свой шрифт» или файлом в `presets/fonts/`. Панель сразу проверяет кириллицу и предупреждает, если её нет |
| Плотность реза | Слайдер с подсказкой, что означает каждое значение |
| Карта реза | После монтажа: мятным — что осталось, серым — вырезанные паузы. Видно, не слишком ли жёстко срезано |
| Что делать | Любой этап выключается: рез пауз, паразиты, крупность, субтитры, шумодав, громкость. Готовые наборы — «Всё», «Только субтитры», «Только рез», «Ничего» |
| Закрепить настройки | Настройки из панели становятся основными — их же берёт CLI |

Выключенные этапы не просто игнорируются: если не нужны ни рез, ни субтитры, распознавание речи
вообще не запускается — ролик собирается за пару секунд вместо минуты.

Правки стиля пересчитываются за пару секунд: транскрипт кэшируется и заново не считается.

## Что делает

| Шаг | Что происходит |
|---|---|
| Распознавание | Whisper large-v3-turbo локально, с таймингом каждого слова |
| Рез | Вырезает паузы, «э-э», «как бы», заикания и повторы |
| Динамика | Меняет крупность кадра на склейках — рез не читается, картинка не замирает |
| Субтитры | Слова появляются по одному, текущее подсвечено — как в CapCut |
| Голос | Фильтр низов, шумодав, компрессия, громкость к −14 LUFS (стандарт соцсетей) |

## Настройка

Всё в `presets/viral.json` — код трогать не нужно. Таблица «что просят → что менять» лежит
в `.claude/skills/reels/SKILL.md`.

Самое частое:
- `cut.max_silence` — плотность темпа (меньше = жёстче рез)
- `subs.font_size`, `subs.margin_v` — размер и высота субтитров
- `subs.color_active` — цвет подсветки текущего слова
- `subs.accent_words` — ключевые слова другим цветом

## Стек

Всё открытое и локальное, одинаковое на Mac и Windows:

- **ffmpeg** (с libass) — рез, субтитры, кодирование: на Mac аппаратный кодек, на Windows `libx264`
- **Whisper large-v3-turbo** (MIT) — распознавание речи: mlx-whisper на Apple Silicon, faster-whisper на остальных
- **YuNet** (OpenCV, MIT) — поиск лиц для камеры-оператора
- **MediaPipe Selfie Multiclass** (Apache-2.0) — вырезка человека для текста «за спиной»
- **EasyOCR** (Apache-2.0) — текст в кадре при разборе референсов
- **HyperFrames** (Apache-2.0) + Chromium — графика из HTML; анимация — GSAP (бесплатна, но лицензия не OSI)
- **Montserrat, Manrope, Oswald и др.** (OFL) — шрифты с кириллицей в `presets/fonts/`

Модели и их лицензии — `scripts/models.py`; скачиваются при установке, монтаж идёт без сети.

## Папки

```
input/    — сюда сырые видео
output/   — отсюда готовые ролики (варианты A/B: <имя>--<стиль>_vN.mp4)
work/     — транскрипты, дубли, решения (brief.json, edit.json, director.json, page.py), очередь
studio/   — проекты HyperFrames: страница графики и её ассеты (пересобираются из work/)
presets/  — стили монтажа (styles/), пресет быстрого конвейера, шрифты, звуки
scripts/  — сам пайплайн и сервер студии
web/      — студия (studio.html) и быстрая панель (index.html)
docs/     — разбор рынка (РЫНОК.md) и замер издержек с планом, что резать (ИЗДЕРЖКИ.md)
.agents/  — скилл reels, общий для Codex и Claude (у Claude — ссылка из .claude/skills)
```

## Проверка после правок

Если что-то менялось в `scripts/`, прогнать самопроверку:

```bash
.venv/bin/python scripts/selfcheck.py          # пара минут, 151 проверка
.venv/bin/python scripts/selfcheck.py --long   # 200 сегментов, если трогал рендер
.venv/bin/python scripts/verify_page.py --all  # все страницы графики, если трогал kit/compose
```

Каждый push в `main` GitHub сам повторяет установку и самопроверку на чистой Windows
(вкладка **Actions** → «Самопроверка на Windows»): машины с Windows под рукой может и не быть.

Самопроверка собирает ролик из синтетического видео и проверяет то, что уже ломалось: расход
памяти, длину ролика относительно плана (иначе субтитры уезжают от речи), уборку
временных файлов, камеру без пустых краёв, субтитры, которые залипали на экране до конца
ролика. Правила проекта — в `AGENTS.md` (`CLAUDE.md` его подключает).

## Требования

Всё ставит `1 Установка — Mac.command` или `1 Установка — Windows.bat` (см. выше); версии Python-пакетов закреплены в
`requirements.txt` — на них пайплайн проверен.

Важно: нужен именно `ffmpeg-full` — обычный `brew install ffmpeg` собран без libass,
и субтитры не наложатся. Установщик это проверяет и подскажет, как переключить.
