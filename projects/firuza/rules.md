# Правила проекта «Фируза — тестовое»

Сторонний заказ (13.10.2026, Валера взял тестовое). Правила этого проекта важнее стиля и умолчаний
скилла; правила антишколы (плашка, CTA, яркость лица 150–152, кодовое слово) сюда не переносятся.

## Задача
- Тестовый ролик ~15 с, вертикаль 9:16, для её Instagram.
- Язык: английский (project.json → language "en").
- Без CTA и без плашки антишколы.

## Стиль
- Референс — instagram.com/reel/DZhDnJ6BIlT (references/links.md): тонкие капсы с засечками цвета
  шампанского (Cormorant) под изумрудно-золотым орнаментом, спокойный ритм, коллаж вокруг героини.
- Картинка — по смыслу фразы, а не «под эстетику» (13.10, Валера про v3: музейные предметы «влетают
  не в кассу, не коррелируют со смыслом»). На каждую фразу — кадр, который читается за полсекунды.
- Без звуковых эффектов (v4: «звук звоночка не к месту»), только тихая музыка под голос.

## Исходник
- Её исходник бывает уже смонтирован: затемнения-переходы между кусками — ищи по яркости кадров у
  краёв фрагмента (IMG_6668: затемнение на 11,8–12,3 с).
- Запись тихая: порог тишины −35 дБ находит «паузы» внутри слов — границы сверяй по rms.py.
