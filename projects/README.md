# projects/ — проекты (данные клиентов)

Здесь живут проекты: `projects/<имя>/` — анкета (`setup.json`), правила (`rules.md`), `project.json`, дизайн-система
(`DESIGN.md`), шрифты бренда (`fonts/`), референсы, а в `input/` и `output/` — видео. В git движка проекты не попадают
(23.10.2026): у каждого человека свои клиенты. Хранить их в своём приватном репозитории — `scripts/clients.py`.

На чистой установке здесь один пустой проект «Мои ролики» (`main`, создаёт установка). Новый проект — в студии:
«Проект → Новый проект», потом анкета «Настроить проект» — без неё ИИ проект не монтирует.
