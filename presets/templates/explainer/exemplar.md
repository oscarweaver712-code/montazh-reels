# Объясняю на фоне — как выглядит хороший ролик (базовый шаблон, 23.10.2026)

Спикер вырезан в нижней части кадра, за ним меняются картинки по мысли: новость, скрин, график, документ — каждые 4–6 с. Под новости, обзоры, технологии, «как это работает».

Стиль — presets/styles/greenscreen.json (там указания режиссёру `director`). Референсы: новостные объяснялки greenscreen (TikTok-новости); OpusClip: Greenscreen explain 2026.

## Раскадровка-мерка (60 с)

| Время | Что на экране |
|---|---|
| 0–2 с | хук картинкой: главный приём шаблона сразу, до первой мысли |
| 2–15 с | завязка: смена на экране не реже раза в 5 с |
| 15–45 с | основная часть: приёмы по моментам речи, нарастают к кульминации |
| 45–55 с | кульминация: самый сильный приём ролика |
| 55–60 с | развязка и призыв словами автора |

## Уроки

- Каждая мысль — новый фон по смыслу фразы (скрин, фото события, график), смена — смазом; фото реальных событий — настоящие, с лицензией.
- Вырезка спикера нужна — маска только по окнам «человек поверх» (matte.py --windows page), снимать со штатива.
- Цифры, даты и названия — крупно (≥ 40 px) и сверены с источником; проверку — в docstring page.py.
- Хук бьёт картинкой в первые 1–2 с, к кульминации приёмы нарастают; у ролика своя визуальная идея из его содержания, не копия прошлого (AGENTS.md).
- Тихие звуки переходов — в каждом ролике; субтитры не прячутся дольше 3 с речи и не двоят крупный текст.

Когда ролик по этому шаблону примут — эталоном станет он: exemplar.video, копия страницы рядом (exemplar.page.py) и лист кадров (templates.py sheets).
