# Шрифты

Все лежащие здесь шрифты — под лицензией SIL Open Font License 1.1. Их можно свободно
использовать в роликах, в том числе коммерческих: платить и указывать авторство в видео
не нужно. Ограничение одно и к монтажу отношения не имеет — нельзя продавать сам файл
шрифта отдельно.

Источник всех: Google Fonts (`fonts.google.com`), взяты статические начертания.
Вариативные файлы сюда класть не надо: libass берёт из них базовое начертание, и вместо
жирного текст выйдет обычным. По той же причине `Montserrat-var.ttf` не участвует —
панель пропускает файлы с `-var` в имени.

нет: без неё русские субтитры выйдут пустыми квадратами.

## Не OFL: шрифты заказчиков (не в git)

Шрифт, который заказчик назвал в ТЗ, берём, даже если он не OFL: лицензия на его ролики — его решение. Такие файлы в
git не кладём (`.gitignore`), рядом с проектом — скрипт, который скачивает их заново.

| Семейство | Файл | Проект и откуда |
|---|---|---|
| Nicoletta script | `NicolettaScript.ttf` | «СлаваМонтаж» (22.10.2026): Nikola Kovanovic, бесплатно кроме коммерческого; Ё/ё дорисованы. `projects/slavamontazh/make_fonts.py` |
| SF Pro Display Light / Regular / Medium / Semibold / Bold | `SF-Pro-Display-*.otf` | «СлаваМонтаж» (22.10.2026): Apple, developer.apple.com/fonts; урезаны до латиницы и кириллицы. Тот же скрипт |
