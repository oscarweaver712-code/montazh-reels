# Шрифты

Все лежащие здесь шрифты — под лицензией SIL Open Font License 1.1. Их можно свободно
использовать в роликах, в том числе коммерческих: платить и указывать авторство в видео
не нужно. Ограничение одно и к монтажу отношения не имеет — нельзя продавать сам файл
шрифта отдельно.

Источник всех: Google Fonts (`fonts.google.com`), взяты статические начертания.
Вариативные файлы сюда класть не надо: libass берёт из них базовое начертание, и вместо
жирного текст выйдет обычным. По той же причине `Montserrat-var.ttf` не участвует —
панель пропускает файлы с `-var` в имени.

| Семейство | Файл | Каким бывает полезен |
|---|---|---|
| Golos Text Black | `GolosText-Black.ttf` | Русский по происхождению, плотный, очень разборчивый |
| Rubik Black | `Rubik-Black.ttf` | Округлый, дружелюбный, хорошо читается в телефоне |
| Unbounded ExtraBold | `Unbounded-ExtraBold.ttf` | Геометрический, широкий — заметный, хорош для хука |
| Fira Sans Condensed ExtraBold | `FiraSansCondensed-ExtraBold.ttf` | Узкий: в строку влезает больше слов |
| Onest Black | `Onest-Black.ttf` | Современный нейтральный гротеск |
| Russo One | `RussoOne-Regular.ttf` | Блочный, «спортивный» |
| Exo 2 Black | `Exo2-Black.ttf` | Техничный |
| Alumni Sans Black | `AlumniSans-Black.ttf` | Очень узкий, экономит место |
| Wix Madefor Display ExtraBold | `WixMadeforDisplay-ExtraBold.ttf` | Аккуратный, спокойный |
| Manrope ExtraBold | `Manrope-ExtraBold.ttf` | Геометрический, мягче остальных |
| Montserrat ExtraBold | `Montserrat-ExtraBold.ttf` | Тот, что стоит по умолчанию |
| Oswald | `Oswald-Bold.ttf` | Узкий, классический для субтитров |
| PT Sans Narrow | `PTSansNarrow-Bold.ttf` | Узкий, но лёгкий — на мелком размере теряется |
| Cuprum | `Cuprum-Bold.ttf` | Узкий, лёгкий — то же замечание |

Свой шрифт добавляется кнопкой в панели. Она сразу проверит кириллицу и скажет, если её
нет: без неё русские субтитры выйдут пустыми квадратами.
