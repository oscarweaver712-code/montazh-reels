# ИИ-футажи: GPT/Nano Banana → Google Flow (Omni) → клип в ролике

Схема перенесена из архива коллеги (`montazh-reels`, 12–14.10.2026, его журнал `engine2/ЖУРНАЛ.md`),
внедрена 16.10.2026 по просьбе Валеры. Подписка Google для генераций — на аккаунте Oscar Weaver.

**Это облако, а не конвейер.** Монтаж работает без него целиком. В Google уходят только промпты и
картинки-референсы (пакшоты, первый кадр) — исходное видео с человеком туда **не отправлять никогда**.
Футаж в ролике — иллюстрация, не документ: реальные события и люди — только настоящими фото.

## Когда футаж к месту

- Фраза про место, быт, процесс, предмет — то, что зритель должен «узнать»: полка «Пятёрочки», кухня,
  касса, конвейер, рука берёт пачку. Это то, что не найти в свободных фото и не нарисовать кодом.
- Не к месту: цифры (это `viz`), формулы (доска), лицо реального человека (только фото, людей не
  генерируем), то, что уже показано словом за спиной.
- Футаж — план во весь кадр 1–2,5 с, спикер возвращается на следующей фразе. Не больше 3–5 на минуту ролика
  без отдельной просьбы: у проекта стиль — говорящий человек (rules.md проекта главнее).

## Порядок

1. **Бриф** — `work/<имя>/footage.json` (решаешь сам по плану ролика, инструмент «футаж» в `plan.md`):
   ```json
   {"budget": 60, "style": "общий хвост стиля ролика по-английски",
    "clips": [{"name": "a_shelf", "at": [12.4, 14.6], "say": "фраза из речи",
               "image": "что в кадре, по-английски, конкретно", "motion": "что двигается, камера",
               "refs": ["materials/pack.png"]}]}
   ```
   `at` — окно по шкале дубля (как `Take.t`), `budget` — бонусы Flow, одобренные Валерой на ролик.
   Без `budget` или сверх него — **спроси до генерации**, назови цену: «5 клипов × 15 = 75 бонусов».
2. **Сообщения для Flow** — `.venv/bin/python scripts/footage.py <имя> --prompts` → `work/<имя>/footage/prompts.md`.
   Хвост стиля (вертикаль, спокойный верх 20%, главное в центральных 80% ширины, без титров) добавляется сам.
3. **Первый кадр** — два пути:
   - Nano Banana прямо во Flow (по умолчанию: держит настоящие упаковки по референсам, пишет кириллицу без ошибок);
   - GPT через Codex: `scripts/footage.py <имя> --frame a_shelf` → `footage/frames/a_shelf.png` (лимит ChatGPT,
     около полутора минут) → загрузить во Flow как первый кадр.
4. **Генерация во Flow** — в Chrome, по разделу ниже. Только Claude Code с расширением Claude in Chrome;
   у Codex и у агента студии без браузера этого шага нет — оставь бриф и prompts.md и скажи Валере.
5. **Приём** — каждый скачанный клип: `scripts/footage.py <имя> --take a_shelf --from 2 --speed 1.5 --credits 15`.
   Без `--file` берётся самый свежий ещё не принятый файл из «Загрузок». Оригинал → `footage/orig/`, под кадр →
   `footage/a_shelf.mp4` (1080×1920, 30 к/с, без звука), рядом `.md` — откуда. Агент студии — через очередь.
6. **Посмотри клип глазами** (`ffmpeg … -vf fps=4,tile` → лист кадров): упаковки не «перетекли», руки целые,
   нет псевдотекста крупно. Плохой кусок — `--to` раньше, иначе перегенерировать (снова с ценой).
7. **В страницу** — `kit.footage("ft1", STEM, "a_shelf", t(12.4), 2.2)` → (html, js) в `front`/`beats`.
   Субтитры поверх футажа — на плашке или с тенью; крупный текст поверх фото — на плашке, фото приглушить.
   `footage.py <имя> --check` — все клипы на месте и не короче окон; потом `verify_page`, рендер как обычно.

## Google Flow в Chrome — как работать (рецепт коллеги)

- **Подключение (16.10.2026):** Google Chrome стоит в /Applications (поставлен с образа Google: Homebrew на этой
  машине упирается в непринятую лицензию Xcode). Нужны расширение Claude in Chrome, вход в нём тем же аккаунтом
  Claude и `/chrome` в Claude Code. Есть ли браузер — видно по инструментам `mcp__claude-in-chrome__*` (загрузить
  через ToolSearch). Нет их — браузера в этой сессии нет: подготовь бриф и prompts.md, скажи человеку
  «запусти `claude --chrome` и попроси сгенерировать футажи», и иди дальше без футажей (их место закрывает графика).

- Адрес — Google Flow (`labs.google/fx/tools/flow`; у коллеги открывался как flow.google.com). Вход —
  аккаунт Oscar Weaver, план с бонусами. **Не входить в чужие аккаунты, не принимать условия и не менять
  план за владельца** — если просит вход или согласие, остановись и скажи.
- Новый проект → в настройках агента Flow: формат 9:16, ×1 (один вариант — бонусы не утекают на лишние).
- Агент в правой панели Flow понимает пачку: **первое сообщение** — все кадры с нумерацией («exactly one
  image per prompt»), **второе** — «animate each image… as the first frame» с движением по каждому
  (оба — из prompts.md). Перед видео агент спрашивает подтверждение с ценой — сверь с `budget`.
- Цены 12.10.2026: видео 6 с — 10 бонусов, 8 с — 12, 10 с Omni Flash — 15. Картинки Nano Banana — дёшево.
- **Enter в поле запроса не отправляет** — только кнопка-стрелка. Во время ответа кнопка становится
  «Остановить»: второй клик отменяет генерацию — не кликай дважды.
- **Загрузка референсов**: input файла появляется только по клику и вне DOM. Рабочий приём — перехватить
  `HTMLInputElement.prototype.click`, чтобы input лёг в DOM вместо системного окна, и отдать файлы через
  загрузку файла инструментом браузера.
- **Скачивание**: 720p — мгновенно и подряд без блокировки; 1080p — апскейл, минуты на файл (не нужен:
  `footage.py` сам приводит к 1080×1920). После скачивания тост «Изображение скачано» ~10 с закрывает пункт
  «1K» в меню — между загрузками ждать ~10 с. Листать просмотр — стрелками, клик по ленте миниатюр не работает.
- Клип: 720×1280, 24 к/с, 10 с. Начинается с покоя, действие — на 5–7-й секунде → `--from` и `--speed 1.5`.
- Omni держит дизайн упаковки первые ~5 с, дальше предметы «перетекают» (пачка одного бренда стала другим) —
  бери кусок до искажения (`--to`). Оборот пачки модель выдумывает — показывать мельком.
- Логотипы и настоящие упаковки брендов в кадре — можно (16.10.2026, Валера снял запрет): узнавание «я это
  видел в магазине» — главный крючок таких роликов. Настоящие упаковки: загрузить пакшоты (с сайта производителя, прозрачный PNG) в проект и просить
  «use these exact products as references… ordinary Russian supermarket, yellow price tags».

## ChatGPT в Chrome (если Codex недоступен)

Бесплатный план — ~3 картинки в сутки. Вторую загрузку подряд Chrome блокирует: картинку забирать кнопкой
«Скопировать изображение» и `osascript -e 'set f to open for access POSIX file "/путь.png" with write permission'
-e 'write (the clipboard as «class PNGf») to f' -e 'close access f'` (буфер Валеры при этом перезаписывается —
предупреди). Основной путь — `footage.py --frame` (Codex), он не трогает браузер.

## Отчёт

Сколько клипов, сколько бонусов ушло (`footage.py <имя>` показывает), какие куски взяты и почему, что спорно
(«пачка на 6-й секунде поплыла — взял до 5,2 с»). Всё нужное следующей сессии — в footage.json, takes.json и
`.md` рядом с клипами, а не в памяти разговора.
