# Монтаж Reels

Два конвейера. **Основной** — режиссёрский: ты (Claude) решаешь, где и чем ударить, графика
собирается в HyperFrames (HTML + GSAP → MP4), всё считается локально. **Быстрый** — старый
ffmpeg-пайплайн: рез пауз, субтитры, голос, без графики.

## Основной конвейер (вирусный монтаж)

Правила автора роликов (не нарушать без спроса): паузы внутри дубля пока НЕ режем; камера следит за
лицом, но кадр всегда полный; у каждой надписи и картинки есть анимация входа И выхода.

```bash
# 1. чистовой дубль: подрезка начала/конца по тишине, цвет (яркость −8), голос
#    решения — в work/<имя>/edit.json: {"trim": [начало, конец], "cut_pauses": false,
#    "drop": [[от, до]]} — drop вырезает неудачный дубль/оговорку с матом. Точки реза ищи по
#    громкости (огибающая RMS по 20 мс), а не по таймингам whisper. Паузы при этом НЕ режутся.
#    На склейке камера сама меняет кадр мгновенно; спрячь рез наездом в director.json:
#    [начало_склейки, конец, 1.2, 0.0, 0.6] — въезд 0 (мгновенно), выезд 0.6 с.
.venv/bin/python scripts/prep.py input/IMG_XXXX.MOV

# 2. лицо и камера-оператор (Apple Vision); превью рамки камеры — aroll.camera.jpg
.venv/bin/python scripts/track.py work/IMG_XXXX/aroll.mp4

# 3. маска человека (Apple Vision) и он же без фона — слой поверх текста «за спиной»
.venv/bin/python scripts/matte.py work/IMG_XXXX/aroll.mp4 --backend vision --cutout

# 4. проект studio/IMG_XXXX/: камера с акцентами, субтитры, ассеты
#    решения режиссёра — work/<имя>/director.json (punches, text_fixes, hide_captions)
.venv/bin/python scripts/compose.py IMG_XXXX

# 5. графика ролика — work/IMG_XXXX/page.py (kit.Take + build_page) пишет studio/IMG_XXXX/index.html
#    образец всего словаря приёмов: work/IMG_3317/page.py → studio/IMG_3317/index.html
.venv/bin/python scripts/verify_page.py IMG_XXXX   # 2 с: ничего не залипнет, ассеты на месте
cd studio/IMG_XXXX && npx --yes hyperframes@0.8.141 lint
npx --yes hyperframes@0.8.141 snapshot --no-end --describe false --at 1.7,5.2,...   # глазами

# 6. готовый ролик: compose → verify_page → render --strict → мастеринг → verify_render
.venv/bin/python scripts/render_reel.py IMG_XXXX   # версия — следующая свободная в output/
```

Порядок работы режиссёра:
1. Прочитай транскрипт (`work/<имя>.txt`, тайминги — `aroll.words.json`), найди мусор в начале
   и конце, предложи хук. Спорные места распознавания перепроверь, а не угадывай.
2. Распиши удары по словам: крупное слово за спиной (не чаще раза за мысль, лицо не закрывать),
   карточки-портреты в верхних углах, документы и формулы снизу, субтитры на груди (y≈1150).
3. Ассеты — только бесплатные: Wikimedia Commons (проверяй лицензию, PD), Pexels/Pixabay,
   звуки — `presets/sfx` (Pixabay License), шрифты — `presets/fonts` (OFL, с кириллицей).
4. `verify_page` и `lint` до нуля ошибок → `snapshot` ключевых моментов → правки → `render_reel.py`.
5. Готовый ролик — в `output/`. Отчитайся: что где на экране, сколько считалось, что спорно.

Ловушки, на которые уже наступали:
- Портреты Vision: только через `CGDataProviderCreateWithCFData`, иначе утечка 2 МБ на кадр.
- `VNGeneratePersonSegmentationRequest` создаётся через `initWithCompletionHandler_(None)`.
- RVM выкидывает предметы в руках (банку) в фон — для наших съёмок не годится.
- В HyperFrames: не анимировать `letterSpacing` (дёргается), буквам для движения нужен
  `display: inline-block`, у появляющегося через `fromTo` элемента видимость должна быть в
  конечных значениях (холодный старт воркера), повторные `fromTo` — с `immediateRender: false`.
- Cormorant по умолчанию рисует старинные цифры (0 похож на «o») — для формул `lining-nums`.
- Координаты на картинках-документах не угадывай на глаз — считай по пикселям.
- Apple Vision иногда не считает предмет в руке (банку) частью человека. Подменённый фон
  (`#plate`) давай только сверху с переходом в родной кадр (`mask-image: linear-gradient(...)`),
  иначе на смене фона предмет просвечивает картиной.
- Крупная буква/слово за головой: перекрестье и середина должны быть ВЫШЕ головы с учётом
  акцентного наезда — на зуме 1.26 голова крупнее и закрывает больше (X превращается в «V»).
- Если справа висит карточка-портрет (x ≥ 744), крупный текст сдвигай в левые 740 px.
- Новый ролик быстрее всего собирать из страницы прошлого: стили и словарь движения
  (`enter/leave/slam/card/doc/flash/bars`) копируются как есть, пишутся только элементы и удары.
- По времени (ролик 44 с): от исходника до готового файла 15 минут, из них машина —
  распознавание 18 с, дубль ~1 мин, маска+вырезка ~4 мин, рендер 4,5 мин, мастеринг+проверка 30 с.
- Снимок не видит залипаний: он прыгает сразу во время, а рендер шагает по кадрам. Уход (`set` или
  короткий `to`), сработавший посреди появления, в рендере проигрывает — элемент висит до конца ролика,
  следующие бегут поверх (так залипли субтитры в пяти роликах из пятнадцати). Ловит
  `verify_page.py`: гоняет таймлайн как рендер. Уход ставь не раньше конца появления; вспышки
  субтитров короче 0.15 с compose сам сливает со следующими.
- Системный шрифт macOS (арабская вязь Geeza Pro, деванагари Kohinoor) — только через
  `@font-face { src: local("Geeza Pro Bold") }`, иначе lint даёт ошибку и `render --strict` не
  пустит в рендер. Объявляй само начертание: `local("Geeza Pro Bold"), local("GeezaPro-Bold")`.
- Пачка роликов идёт через очередь `scripts/jobqueue.py` (`work/_queue/*.sh`, один тяжёлый процесс
  за раз, порядок по префиксу: 01-check, 02-selfcheck, 05-render, 10-transcribe, 20-prep). Задача
  рендера — одна строка `render_reel.py IMG_XXXX --version vN`. Не собирай её из `npx … render |
  grep … || true`: так упавший рендер проходил молча, и в output/ мог уехать прошлый файл. Раскладку
  ударов пиши в `work/<имя>/page.py` по таймингам ИСХОДНИКА через `kit.Take` — `t(сек)` сам учтёт
  сдвиг начала и вырезы, `fixes({номер_слова: текст})` переведёт номера слов. Момент внутри выреза —
  громкая ошибка, а не тихий сдвиг.
- Кодовое слово в конце («пиши в комментариях экономика») — `kit.keyword_card` + `keyword_beats`.
- Субтитры: whisper рвёт «по-индийски», «80+», «1,2» на части — дефисные хвосты и «+»/«%»
  приклеиваются сами, а «1» + «,2» правь через text_fixes («1,2» и ""). Пустая строка в text_fixes
  убирает слово, «***» — для слова под «пипом».
- Спорное слово перепроверяй: короткий кусок и кусок с контекстом через whisper (10-recheck-job) и
  огибающую громкости `scripts/rms.py` — два слога или один, где тишина. «Как деньги» так и нашлось.
- Факты в речи сверяй (даты, формулы, ответы задач) и пиши проверку в docstring page.py.

## Быстрый конвейер

Пайплайн на ffmpeg + mlx-whisper: на входе сырое вертикальное видео, на выходе mp4 с резом пауз
и субтитрами, без графики.

## Два способа работы

Быстрый конвейер удобно гонять через **панель**: двойной клик по `Монтаж.command` → браузер на
`127.0.0.1:8765`. Там же настройки, превью субтитров и карта реза. Если просят
«запусти панель» — стартуй `.venv/bin/python scripts/server.py`.

Настройки, закреплённые в панели, пишутся в `presets/viral.json` — то есть панель и CLI
делят один пресет.

## Команды

```bash
# всё, что лежит в input/
.venv/bin/python scripts/reels.py

# конкретный файл
.venv/bin/python scripts/reels.py input/urok.mp4

# с текстовым хуком поверх первых секунд
.venv/bin/python scripts/reels.py input/urok.mp4 --hook "Так делают 90% учеников"
```

Флаги: `--no-cut` (не резать паузы), `--no-subs`, `--no-motion` (без смены крупности),
`--no-audio` (не трогать звук), `--force` (пересчитать транскрипт),
`--encoder libx264` (качественнее, медленнее), `--out имя.mp4`, `--preset <имя>`.

## Выключаемые этапы

Любой этап отключается — и в панели, и флагом. В пресете это `cut.enabled`, `subs.enabled`,
`motion.punch_in`, `audio.enabled`, `audio.denoise`, `audio.normalize`, `cut.remove_fillers`.

Если выключены и рез, и субтитры — распознавание речи пропускается целиком (иначе это минута
впустую). Когда просят «только субтитры» или «просто перегони в формат» — пользуйся этим,
не гоняй whisper зря.

## Порядок работы

1. **Всегда сначала прочитай транскрипт** `work/<имя>.txt` перед тем, как что-то советовать по нарезке или хуку. Не предлагай хук вслепую.
2. Прогон пайплайна.
3. Отчитайся цифрами: сколько вырезано, какой хронометраж стал.

## Что где настраивается

Всё в `presets/viral.json`, код трогать не нужно:

| Что просят | Что менять |
|---|---|
| «режет слишком много / рвано» | `cut.max_silence` ↑ (0.35–0.45) |
| «слишком вяло, много воздуха» | `cut.max_silence` ↓ (0.20–0.24) |
| «съедает нужные слова» | убрать слово из `cut.fillers` |
| «субтитры мелкие/крупные» | `subs.font_size` |
| «субтитры не там по высоте» | `subs.margin_v` (больше = выше) |
| «другой цвет подсветки» | `subs.color_active` |
| «другой шрифт» | `subs.font` — это **имя семейства**, а не имя файла. Файл положить в `presets/fonts/` |
| «слов в строке много/мало» | `subs.words_per_phrase` |
| «картинка дёргается» | `motion.min_hold_sec` ↑ или `motion.punch_in: false` |
| «тихо / громко» | `audio.loudness_target` (-14 стандарт соцсетей) |

Ключевые слова можно подсветить отдельным цветом: `subs.accent_words: ["дискриминант", "формула"]`.

## Нарезка длинного урока на несколько Reels

Пайплайн сам этого не делает — нарезка требует смысла, это твоя работа:

1. Прогони транскрибацию, прочитай `work/<имя>.txt`.
2. Выбери 3–5 самодостаточных кусков: каждый должен быть понятен без контекста и начинаться с сильной фразы.
3. Нарежь исходник по таймкодам и прогони каждый кусок отдельно:
   ```bash
   ffmpeg -y -i input/urok.mp4 -ss 124.5 -to 168.0 -c copy input/urok_part1.mp4
   ```
   Тайминги бери из `work/<имя>.words.json` — режь по границам слов, не в середине.
4. Прогони пайплайн по каждому куску, каждому — свой `--hook`.

## Шрифты

Лежат в `presets/fonts/`, поддерживаются `.ttf` и `.otf`. В `subs.font` пишется **имя семейства**
(name ID 1), а не имя файла — по нему libass ищет шрифт. Узнать имя:

```bash
.venv/bin/python -c "
from fontTools.ttLib import TTFont
f=TTFont('presets/fonts/ИМЯ.ttf',fontNumber=0)
print(f['name'].getDebugName(1))"
```

Две ловушки:
- **Нет кириллицы** — субтитры выйдут пустыми квадратами. Панель проверяет автоматически, при
  ручной правке пресета проверь сам. Если libass не найдёт шрифт по имени, он молча подставит
  другой — поэтому после смены шрифта посмотри кадр из результата.
- **Вариативные шрифты** (`Font[wght].ttf`) libass берёт в обычном начертании, жирность теряется.
  Запеки статический вес через `fontTools.varLib.instancer` — так сделан Montserrat ExtraBold.

## Важное

- Исходники вертикальные (9:16). Горизонтальный обрежется по центру — предупреди.
- Транскрипт кэшируется в `work/`. При смене настроек субтитров/реза он переиспользуется, whisper заново не гоняется — это быстро. Пересчёт только с `--force`.
- ffmpeg должен быть `ffmpeg-full` (с libass). Обычный brew-овский `ffmpeg` собран без него, субтитры не наложатся.
- Первый прогон нового стиля почти никогда не идеален. Меняй **один параметр за раз** и показывай результат.
